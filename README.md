# Hypothesis Testing: Maximizing Revenue

## Project Overview
This project uses statistical analysis and hypothesis testing to investigate differences in average fares between credit card and cash payments in NYC Yellow Taxi trip data.

## Objectives
- Perform exploratory data analysis (EDA).
- Clean and prepare the dataset.
- Visualize fare distributions and relevant variables.
- Conduct an independent-samples t-test.
- Interpret the statistical results and identify business implications.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Jupyter Notebook
