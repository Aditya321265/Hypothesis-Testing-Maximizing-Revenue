# Hypothesis Testing: Maximizing Revenue

## Project Overview
This project uses statistical analysis and hypothesis testing to investigate differences in average fares between credit card and cash payments in NYC Yellow Taxi trip data.

## Objectives
- Perform exploratory data analysis (EDA).
- Clean and prepare the dataset.
- Visualize fare distributions and relevant variables.
- Conduct an independent-samples t-test.
- Interpret the statistical results and identify business implications.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Jupyter Notebook

## Dataset
This project uses the **NYC Yellow Taxi Trip Records for January 2020**, which contain taxi trip information used to explore fare patterns and payment methods.

- **Source:** [NYC Taxi & Limousine Commission (TLC) Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)
- **Dataset file:** `yellow_tripdata_2020-01.csv`
- **Purpose:** To analyze differences in fares between credit card and cash payments using exploratory data analysis and statistical hypothesis testing.
- **Availability:** The raw dataset is not included in this repository because of its large file size. Download the January 2020 Yellow Taxi trip data from the official source above and place the CSV file in the project's `data/` folder before running the notebook.

**Attribution:** Dataset provided by the New York City Taxi & Limousine Commission (NYC TLC).

## Disclaimer
This is an educational data analytics project. Statistical differences do not, by themselves, establish causation.
